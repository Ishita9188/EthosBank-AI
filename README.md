# EthosBank-AI
EthosBank AI is an AI-powered ethical banking and consumer protection platform that combines digital banking, financial wellness analysis, debt-risk prediction, savings forecasting, spending behaviour analysis, explainable AI, and smart detection of manipulative banking offers.
